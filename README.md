# Google Landing Page Clone

A clean, lightweight clone of the Google Search homepage built using HTML and CSS.
Demo link -  https://googledemo-green.vercel.app


## Features

- **Top Navigation Bar:** Includes links for **Gmail**, **Images**, and a styled **Sign in** button.
- **Google Logo:** Styled multi-color Google branding centered on the page.
- **Search Interface:** Rounded search input bar accompanied by **Search**, **Google Search**, and **I'm Feeling Lucky** buttons.
- **Language Options:** "Google offered in" section featuring links for **Hindi**, **Punjabi**, **Bengali**, **Urdu**, and **Marathi**.

---

## Tech Stack

- **HTML5** – Page structure and semantic elements
- **CSS3** – Layout, typography, colors, and button styling

## Getting Started

1. **Clone or download the repository:**
   ```bash
   git clone https://github.com<your-username>/google-clone.git
   ```
2. **Navigate to the project folder:**
   ```bash
   cd google-clone
   ```
3. **Run the project:**
   - Open `index.html` directly in any web browser, **or**
   - Use the **Live Server** extension in VS Code (click **Go Live** in the bottom-right corner).
